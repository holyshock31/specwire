使用提示

先配置 GitLab / Multica 实例，再在 Connection 向导中选择源 Group、源项目、目标 Workspace 和目标项目。资源 provisioning 完成后，在 Connection 下从模板创建 Flow。
Flow 只有发布后才会激活共享 Hook 路由；Connection onboarding 本身不会执行事件流。
