# Triage labels

The `triage` skill is available for this repository. Use the following canonical labels exactly; no existing equivalent labels were found in the repository, so there is no alias mapping:

| Label | Meaning |
|---|---|
| `needs-triage` | New or unclassified item that needs initial routing. |
| `needs-info` | Work is blocked until the requester supplies missing information. |
| `ready-for-agent` | Scope and prerequisites are clear enough for agent implementation. |
| `ready-for-human` | A human decision, approval, or review is required next. |
| `wontfix` | The item is intentionally not being pursued. |

`change` is reserved for the SpecWire publication workflow and is not a substitute for a triage label. `SpecWire-Status` and `SpecWire-Assignee` are Issue description fields, not labels.
